투자 일지 & 수익률 계산

기록하지 않으면 실수를 반복한다.
투자 일지는 단순 기록이 아니라 자신의 투자 시스템을 만드는 과정.

1. 투자 일지가 필요한 이유

투자 일지의 효과

1. 매수·매도 근거 기록 → 감정적 결정 방지
2. 성공·실패 패턴 발견 → 지속적 개선
3. 수익률 정확한 추적 → 실제 성과 파악
4. 세금 신고 근거 자료 → 절세
5. 투자 철학 정립 → 흔들리지 않는 원칙

2. 투자 일지 구성 요소

3. 수익률 정확한 계산법

단순 수익률 (기본)

단순 수익률 = (현재가치 - 취득가치) / 취득가치 × 100

예시:
1,000만원 → 1,200만원
수익률 = (1,200 - 1,000) / 1,000 × 100 = 20%

한계: 추가 입금·출금 시 정확하지 않음

TWR (시간가중수익률)

TWR = Time-Weighted Return
→ 현금 흐름(입출금) 영향을 제거한 투자 능력 순수 측정
→ 펀드매니저 성과 비교에 사용

계산 방법:
기간별 수익률을 모두 곱함

예시:
1분기: 1,000만원 → 1,100만원 = +10%
중간에 500만원 추가 입금 (총 1,600만원)
2분기: 1,600만원 → 1,800만원 = +12.5%

TWR = (1 + 0.10) × (1 + 0.125) - 1 = 23.75%

→ 추가 입금한 500만원이 언제 들어왔는지 관계없이 순수 투자 능력 측정

MWR (금액가중수익률) = XIRR

MWR = Money-Weighted Return
→ 내부수익률(IRR) = 현금흐름을 반영한 실제 수익률
→ 나의 실제 돈이 얼마나 불었는가

엑셀 XIRR 함수 활용:
=XIRR(현금흐름 범위, 날짜 범위)

예시:
날짜        현금흐름
2026-01-01  -10,000,000 (초기 투자)
2026-04-01  -5,000,000  (추가 투자)
2026-12-31  +17,000,000 (최종 가치)

=XIRR → 연환산 수익률 계산

벤치마크 비교

수익률 의미 있게 보려면 벤치마크와 비교:

내 수익률 15% vs 코스피 15% → 시장과 동일 (알파 없음)
내 수익률 15% vs 코스피 5%  → 알파 +10% (우수)
내 수익률 5%  vs 코스피 15% → 알파 -10% (인덱스 ETF가 나음)

권장 벤치마크:
- 국내 주식: 코스피 또는 코스닥
- 미국 주식: S&P500 (SPY)
- 전체 포트폴리오: 자산배분 비중에 맞는 혼합 지수

4. 포트폴리오 추적 도구

엑셀 포트폴리오 관리

추천 항목:
A: 종목명
B: 매수일
C: 매수가
D: 수량
E: 취득금액 (C×D)
F: 현재가
G: 평가금액 (F×D)
H: 손익금액 (G-E)
I: 수익률 (H/E×100)
J: 포트폴리오 비중 (G/전체합계)

전체 포트폴리오 수익률:
= SUM(손익금액) / SUM(취득금액) × 100

국내 포트폴리오 관리 앱

앱 특징 추천 대상
나무(NH증권) 국내 자동 연동 국내 주식 위주
증권플러스 다계좌 통합, 수익률 계산 멀티 계좌
Stock Note 거래 일지 중심 매매 기록 중시
야후 파이낸스 해외 주식 포트폴리오 해외 주식 위주

5. 투자 복기 (Review) 시스템

월간 복기

매월 말 체크:
□ 월간 수익률 기록
□ 벤치마크(코스피/S&P500) 대비 성과
□ 가장 잘한 결정 1가지
□ 가장 아쉬운 결정 1가지
□ 다음 달 주목할 일정 (FOMC, 실적 발표 등)

연간 복기

연말 심층 복기:
□ 연간 TWR · MWR 계산
□ 벤치마크 대비 알파 계산
□ 매수·매도 근거 재검토
□ 성공한 투자의 공통점
□ 실패한 투자의 공통점
□ 손절을 잘 했는가 → 손절 타이밍 평가
□ 심리적 실수 목록 (공포 매도, 탐욕 보유)
□ 내년 투자 전략 수정

패턴 분석 예시

내 투자 패턴 분석 (예시):

강점:
- 가치주 발굴 성공률 70%
- 큰 하락장에서 추가 매수 잘함

약점:
- 손절이 늦음 (평균 -20% 이후 손절)
- 테마주 단기 매수로 손실 반복
- 급등 종목 뒤늦게 추격 매수 실수

개선 방향:
- 손절선 -10%로 엄격 준수
- 테마주 종목 수 전체의 10% 이내
- 급등 후 3일 이내 진입 금지

6. 수익률 계산 실수 주의

흔한 오류

오류 1: 세금·수수료 미포함
→ 실제 수익률 = 수익 - 세금 - 수수료

오류 2: 배당금 누락
→ 총수익률 = 매매차익 + 배당금

오류 3: 환율 미반영 (해외 주식)
→ 원화 기준 수익률 = 주가수익률 + 환율수익률

오류 4: 추가 입금 미반영
→ 단순 % 계산 시 과대평가 가능
→ MWR(XIRR)로 정확히 계산

올바른 계산:
실제 수익률 = (매도금액 + 배당금 - 세금 - 수수료 - 매수금액) / 매수금액 × 100
