미국 주식 직접 투자 실무

미국 주식은 국내 주식보다 세금·환율·시차 등 고려할 것이 많다.
한 번 제대로 세팅하면 글로벌 최고 기업에 직접 투자할 수 있다.

1. 계좌 개설 & 환전

증권사 선택 기준

증권사 해외주식 수수료 환전 스프레드 특징
토스증권 0.1% 1% (이벤트 시 0%) 소수점 매수, UI 최강
키움증권 0.25% 1% HTS 기능 풍부
미래에셋 0.25% 1% 글로벌 서비스
한국투자증권 0.25% 0.5~1% 이벤트 수수료 할인
삼성증권 0.25% 1% 안정성

장기 ETF 투자: 토스증권 (0.1% 수수료 + 소수점 매수)
적극적 개별주 거래: 키움 영웅문 (낮은 수수료 + HTS 기능)

환전 방법

방법 1: 직접 환전 (수동)
→ 원화 → 달러 환전 후 매수
→ 환율 좋을 때 미리 환전 가능
→ 환전 스프레드 1% 발생

방법 2: 자동 환전 (즉시)
→ 매수 시 자동으로 원화 → 달러 환전
→ 편리하지만 환전 타이밍 선택 불가

환전 최적 타이밍:
- 달러 강세(원화 약세) 시 환전 자제
- 달러 약세 시 달러 매수 (원화 강세 시점)
- 월 1회 정기 환전으로 환율 리스크 분산

환율 리스크 관리

달러 강세 효과:
- 미국 주식 수익률 = 주식 수익률 + 환율 수익률
- 원화 약세(달러 강세) → 국내 투자자 추가 수익
- 원화 강세(달러 약세) → 환율 손실 발생

예시:
S&P500 ETF 연수익률 10% + 달러 5% 강세
= 국내 투자자 실질 수익 약 15%

S&P500 ETF 연수익률 10% - 달러 5% 약세
= 국내 투자자 실질 수익 약 5%

헤지 방법: 환헤지(H) 상품 선택 (환율 변동 제거)
단, 환헤지 비용 연 1~2% 추가 발생

2. 미국 주식 세금 완전 정리

세금 종류

세금 과세 대상 세율 신고 방법
양도소득세 매매 차익 22% (250만원 공제) 5월 종합소득세 신고
배당소득세 미국 배당 수령 미국 15% 원천징수 별도 신고 (이미 원천징수)
금융소득 종합과세 국내 배당 포함 연 2,000만원 초과 종합세율 종합소득세에 포함

양도소득세 계산

과세표준 = 양도금액 - 취득금액 - 250만원 (기본공제)

세금 = 과세표준 × 20% + 지방소득세 2% = 22%

예시:
애플 주식 매수: 3,000만원
매도: 4,500만원
수익: 1,500만원

양도소득세 = (1,500만원 - 250만원) × 22% = 275만원

주의: 해외주식은 손익 통산 가능
→ 수익 종목 1,500만원 + 손실 종목 -500만원
→ 순이익 1,000만원 - 250만원 = 750만원 × 22% = 165만원

절세 전략

1. 손익 통산 활용:
   수익 종목과 손실 종목 같은 해에 매도
   → 손실로 수익 상쇄

2. 매년 250만원 공제 활용:
   연간 수익이 250만원 이하면 세금 0
   → 장기 보유 시 분할 매도로 공제 누적 활용

3. 연금계좌(IRP·연금저축) 활용:
   연금계좌 내 해외 ETF 투자 → 매매차익 비과세
   수령 시 연금소득세(3.3~5.5%)만 납부

4. 배우자 증여 후 매도:
   배우자에게 6억원 공제 내 증여
   증여받은 날 시가가 새 취득가액
   → 차익 축소

양도소득세 신고 방법

신고 기간: 매년 5월 (전년도 소득)

방법 1: 홈택스 직접 신고
→ 국세청 홈택스 → 세금신고 → 양도소득세
→ 증권사에서 거래내역 다운로드 후 입력

방법 2: 증권사 대행 신고
→ 일부 증권사(키움·미래에셋) 신고 대행 서비스
→ 비용: 무료~3만원

방법 3: 세무사 위임
→ 복잡한 경우 (여러 증권사, 손익 복잡)
→ 비용: 10~30만원

3. 배당주 투자 실전

미국 배당 수령 프로세스

배당 일정:
1. 배당 발표일 (Declaration Date)
2. 배당락일 (Ex-Dividend Date): 이날 보유해야 배당권리 있음
3. 배당 기준일 (Record Date)
4. 배당 지급일 (Payment Date)

배당락일 전날 주식 보유 → 배당 수령
배당락일 당일 매수 → 배당 없음

세금:
→ 미국에서 15% 원천징수 후 입금
→ 국내 신고 불필요 (이미 15% 납부)
→ 종합소득 2,000만원 초과 시 종합과세 주의

DRIP (배당 재투자 프로그램)

DRIP = Dividend Reinvestment Plan
→ 배당금을 자동으로 해당 주식 추가 매수

일부 증권사(미국 TD Ameritrade, Fidelity)에서 지원
국내 증권사: 자동 DRIP 기능 미지원 (수동 재투자)

복리 효과 계산:
배당수익률 3%, 주가 성장 7%, 연 총수익 10%
DRIP 미사용: 20년 후 원금의 6.73배
DRIP 사용: 20년 후 원금의 7.40배 (+10% 추가)

SEC 공시 읽기

10-K = 연간 보고서 (우리나라 사업보고서)
10-Q = 분기 보고서
8-K  = 수시 공시 (중요 사항 발생 시)
DEF 14A = 주주총회 안건 (임원 보수 확인 가능)

읽는 순서:
1. MD&A (경영진의 재무상태 논의): 회사 방향 파악
2. Risk Factors: 위험 요소 확인
3. Financial Statements: 재무제표
4. Note to Financial Statements: 세부 사항

5. 소수점 매수 활용

소수점 매수란?

1주 미만 거래 가능:
→ 테슬라 1주 = <span class="math-inline">$250 → 0.1주 = $</span>25으로 투자 가능
→ 버크셔 해서웨이 A주 $650,000 → 소액으로 분산 가능

지원 증권사:
- 토스증권: 소수점 매수 지원 (0.001주까지)
- 카카오페이증권: 지원
- 키움증권: 미지원 (정수 단위만)

활용:
→ 매월 정해진 금액으로 여러 종목 분산 매수 가능
→ 포트폴리오 비중 정밀 조정 가능

정기 자동 매수 설정

토스증권 자동 매수:
→ 매월 특정 날짜에 지정 금액으로 자동 매수
→ 달러-코스트 에버리징(DCA) 효과
→ 감정 배제한 기계적 투자 가능

예: 매월 1일 애플 <span class="math-inline">$100, 마이크로소프트 $</span>100, S&P500 ETF $100 자동 매수
