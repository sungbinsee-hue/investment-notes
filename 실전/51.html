퇴직연금 DC형 실전 운용

퇴직연금은 장기 투자의 핵심.
잘 운용하면 은퇴 자산이 2배 이상 차이날 수 있다.

1. 퇴직연금 3종류 완전 비교

DB·DC·IRP 차이

구분 DB (확정급여형) DC (확정기여형) IRP (개인형)
누가 운용 회사 근로자 본인 개인
급여 방식 근속연수 × 최종 임금 운용 실적에 따라 운용 실적에 따라
투자 결정 회사 근로자 본인 개인
원금 보장 실질적 보장 없음 (운용 결과) 없음 (운용 결과)
추가 납입 불가 가능 가능
세액공제 없음 추가납입 분 연 900만원 한도

어떤 제도가 유리한가?

DB 유리한 경우:
- 임금 인상이 빠른 회사 (호봉제, 공공기관)
- 장기 재직 예정

DC 유리한 경우:
- 임금 인상이 느린 회사
- 투자에 자신 있는 경우
- 성과급 비중 높은 경우 (성과급도 DC 적립 가능)

IRP:
- DB·DC에 추가로 개설 가능
- 퇴직금 받을 때 의무 수령 계좌
- 개인 추가 납입으로 세액공제 활용

2. 세액공제 완전 정리

연금저축 + IRP 세액공제

항목 한도 세액공제율
연금저축 (단독) 연 600만원 13.2% 또는 16.5%
IRP (단독 또는 연금저축 + IRP) 연 900만원 (합산) 13.2% 또는 16.5%

공제율 구분:
- 총급여 5,500만원 이하 (종합소득 4,500만원 이하): 16.5%
- 총급여 5,500만원 초과: 13.2%

최대 절세 계산 예시 (급여 5,500만원 이하):

연금저축 600만원 + IRP 300만원 = 900만원 납입
세액공제 = 900만원 × 16.5% = 148.5만원 절세

납입 전략

우선순위:
1. IRP에 300만원 납입 (세액공제 극대화)
2. 연금저축에 600만원 납입 (합산 900만원)
3. DC 자발적 추가납입 (별도 세액공제 없지만 운용수익 비과세)

주의:
- 연금저축 펀드 > 연금저축 보험 (수수료 차이 크다)
- IRP는 안전자산 30% 이상 의무 보유 (ETF·펀드만으로는 70%까지)

3. DC형 퇴직연금 운용 전략

디폴트옵션 확인

디폴트옵션 = 별도 지시 없을 때 자동으로 운용되는 기본 상품

2023년부터 의무화:
- 초저위험: 원리금보장형 (예금·RP)
- 저위험: 채권형 펀드
- 중위험: 혼합형 펀드
- 고위험: 주식형 펀드·TDF

현재 내 디폴트옵션 확인 방법:
→ 퇴직연금 사업자 앱(증권사·은행) 로그인 → 내 퇴직연금 현황

DC형 자산배분 전략

나이별 기본 주식 비중:

주식 비중 = 100 - 나이 (보수적)
또는: 120 - 나이 (공격적)

30세: 주식 70~90% / 채권 10~30%
40세: 주식 60~80% / 채권 20~40%
50세: 주식 40~60% / 채권 40~60%
60세 이상: 주식 20~40% / 채권 60~80%

TDF (Target Date Fund) 활용

TDF = 은퇴 목표 시점에 맞춰 자동으로 주식 비중을 줄이는 펀드

예: TDF2045 → 2045년 은퇴 예정자용
- 현재(2026): 주식 80%, 채권 20%
- 2035년: 주식 60%, 채권 40%
- 2045년: 주식 30%, 채권 70%

장점: 리밸런싱 자동화, 감정 배제
단점: 운용보수 0.3~0.5% (인덱스 ETF보다 높음)

DC형 추천 포트폴리오 (2026년)

상품 비중 이유
KODEX 미국S&P500 40% 글로벌 성장
TIGER 미국나스닥100 20% 기술주 성장
KODEX 국내채권(국고채) 20% 안정성
TIGER 리츠부동산인프라 10% 배당·분산
KODEX 골드선물(H) 10% 인플레 헤지

IRP는 안전자산 30% 이상 의무 → 채권+금 합산 30% 이상 유지

4. 연금 수령 전략

연금 수령 시 세금

연금소득세 (연금으로 수령 시):
- 70세 미만: 5.5%
- 70~80세 미만: 4.4%
- 80세 이상: 3.3%

일시금 수령 시:
- 기타소득세 16.5% (분리과세)

→ 연금으로 수령 시 세금이 훨씬 저렴!
→ 연금수령 기간 늘릴수록 절세

연금계좌 통합 전략

최적 수령 순서:
1. IRP·연금저축 → 70세 이전 수령 (세율 5.5%)
2. 연간 1,500만원 이하 수령 → 종합과세 제외
   (1,500만원 초과 시 종합과세 또는 분리과세 15% 선택)

예시:
연금저축 월 100만원 수령 = 연 1,200만원
IRP 월 25만원 수령 = 연 300만원
합계 연 1,500만원 → 세율 5.5% 이하로 관리

퇴직연금 일시금 vs 연금 비교

퇴직금 1억원 수령 시:

일시금:
→ 퇴직소득세 납부 (근속연수에 따라 감소)
→ 20년 근속: 약 3~5% 실효세율
→ 즉시 사용 가능

IRP 이전 후 연금:
→ 퇴직소득세 30% 감면 (연금 수령 시)
→ 운용 기간 세금 이연
→ 수령 시 연금소득세 3.3~5.5%

결론: IRP 이전 후 연금 수령이 세금 면에서 유리
      단, 55세 이전 인출 시 기타소득세 16.5% 불이익
