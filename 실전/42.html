공모주 IPO 청약 실전

연평균 공모주 수익률(상장일 시초가 기준)은 약 20~30%대.
방법을 알면 원금 보장(환불 가능)에 가까운 단기 수익 기회.

1. IPO 전체 프로세스

기업 상장 결정
    ↓
주관 증권사 선정 (대표 주관사)
    ↓
수요예측 (기관투자자 대상, 2~3일)
    ↓
공모가 확정 (수요예측 결과 반영)
    ↓
일반 청약 (개인투자자, 2일간)
    ↓
환불 (청약일+2일)
    ↓
상장 (청약 마감 후 약 5~7 영업일)

수요예측이 중요한 이유

  • 기관 수요예측 경쟁률이 높을수록 → 상장 후 주가 상승 가능성 높음
  • 수요예측 경쟁률 1,000:1 이상 → 따상(+160%) 가능성 있음
  • 기관 의무보유 확약 비율이 높을수록 → 상장 후 매도 압력 적음

2. 균등배정 vs 비례배정 (2023년 이후 기준)

현행 배정 방식 (50:50 분리 배정)

구분 비율 배정 방식 전략
균등배정 청약 물량의 50% 청약한 모든 사람에게 균등 최소 청약 (증거금 최소화)
비례배정 청약 물량의 50% 청약 수량에 비례 대량 청약 (증거금 극대화)

균등배정 전략 (소액 투자자 유리)

최소 청약 단위: 10주 (대부분)
최소 청약 증거금: 공모가 × 10주 × 50% (증거금률)

예: 공모가 10,000원
최소 증거금 = 10,000 × 10 × 0.5 = 50,000원

→ 5만원으로 균등배정 참여 가능!
💡 균등배정 핵심 전략
여러 증권사에서 같은 공모주 청약 불가 (동일 공모 중복 청약 금지, 2021년부터) 단, **가족 명의 계좌**는 각각 별도 청약 가능 → 가족 활용 시 배정 수량 증가

비례배정 전략 (대규모 자금 보유자)

비례배정 예상 수량 = (내 청약 수량 ÷ 전체 청약 수량) × 비례배정 물량

예: 전체 비례배정 물량 100만주, 내 청약 1,000주, 전체 청약 10억주
예상 배정 = 1,000 ÷ 10억 × 100만 = 0.1주 (거의 0)

→ 비례배정은 수십억 이상 대규모 자금 없으면 효과 미미
→ 소액 투자자는 균등배정에 집중

3. 증거금 계산 실전

증거금률별 필요 금액

공모가 최소 청약 (10주) 증거금률 50% 증거금률 100%
5,000원 50주 기준 125,000원 250,000원
10,000원 50,000원 50,000원 100,000원
50,000원 250,000원 250,000원 500,000원
100,000원 500,000원 500,000원 1,000,000원

증거금은 청약 마감 후 환불일에 배정되지 않은 금액 전액 반환

4. 청약 일정 확인 방법

실전 확인 사이트

사이트 특징 URL
38커뮤니케이션 국내 최다 IPO 정보, 청약 일정·경쟁률 실시간 38.co.kr
금감원 전자공시 (DART) 공식 투자설명서·증권신고서 dart.fss.or.kr
한국거래소 (KRX) 상장 예정 공식 정보 krx.co.kr
IPO스탁 청약 일정 캘린더 ipostock.co.kr
증권사 앱 청약 알림 주관사 앱에서 알림 설정 필수 각 증권사 앱

청약 일정 확인 순서

1. 38커뮤니케이션 → 청약 일정 확인 (월간 캘린더)
2. DART → 해당 기업 증권신고서 검색 → 수요예측 결과·공모 조건 확인
3. 주관 증권사 앱 → 청약 신청
4. 환불일 확인 → 다른 청약에 재활용

5. 상장일 전략

시초가 결정 방식

상장 첫날 오전 8:30~9:00 호가 접수
시초가 = 공모가의 60%~200% 범위에서 결정

따상 = 시초가 200% (공모가 2배) + 상한가 30% = 공모가 대비 +160%
따상상 = 따상 다음날도 상한가 = 공모가 대비 +238%

상장일 행동 유형별 장단점

전략 장점 단점 적합 상황
시초가 즉시 매도 리스크 최소화 추가 상승 기회 놓침 공모가 대비 충분히 상승 시
첫날 보유 후 종가 매도 따상 가능성 하락 시 수익 감소 수요예측 경쟁률 높을 때
2~3일 보유 따상상 가능성 차익실현 매물 리스크 매우 인기 있는 IPO만
장기 보유 기업가치 성장 공모주 특성과 맞지 않음 핵심 성장 기업에만

상장일 주가 패턴 통계 (2023~2025)

  • 공모가 상회 상장: 약 65~70%
  • 따상 달성: 약 10~15%
  • 공모가 하회 상장: 약 30~35%
  • 공모가 하회 1개월 후 회복: 약 50%
⚠️ 공모가 이탈 리스크
따상보다 공모가 하회가 더 흔함. 수요예측 경쟁률 100:1 미만 → 상장 후 부진 가능성 높음. 증거금을 잃지는 않지만 배정받은 주식 손실 가능.

6. 좋은 공모주 선별 기준

정량 체크리스트

  • [ ] 기관 수요예측 경쟁률 1,000:1 이상
  • [ ] 기관 의무보유 확약 비율 30% 이상 (상장 후 매도 압력 ↓)
  • [ ] 공모가 밴드 상단 확정 (기관 수요 강함)
  • [ ] 상장 주식 수 대비 공모 물량 소규모 (유통 주식 적을수록 주가 상승 용이)
  • [ ] 주관 증권사 대형사 (미래에셋·KB·NH 등)

정성 체크리스트

  • [ ] 성장 스토리가 명확한가
  • [ ] 유사 기업 대비 공모가 적정한가 (PER 비교)
  • [ ] 최대주주 보호예수 기간 확인 (6개월~1년)
  • [ ] 사용 목적 자금 명확한가 (시설 투자 vs 대주주 현금화)

7. 주요 증권사 공모주 청약 비교

증권사 특징 수수료 계좌 개설
미래에셋증권 대형 IPO 주관사 多, 앱 편의성 우수 무료 비대면 가능
KB증권 대형 IPO 공동 주관사 多 무료 비대면 가능
NH투자증권 나무(NAMUH) 앱 편의성 우수 무료 비대면 가능
키움증권 개인투자자 점유율 1위 무료 비대면 가능
삼성증권 대형 IPO 참여 多 무료 비대면 가능
💡 실전 팁
**여러 증권사 계좌 개설 필수**: 주관 증권사에서만 청약 가능 → 주관사가 다를 때마다 다른 계좌 필요 단, 같은 IPO는 한 증권사에서만 청약 (중복 청약 금지)

8. 실전 청약 단계별 가이드

D-10: 38커뮤니케이션에서 공모 일정 확인
D-5:  DART에서 증권신고서 다운로드 → 기업 개요·재무·리스크 확인
D-3:  수요예측 결과 확인 (경쟁률, 공모가 확정)
D-1:  청약 전날 주관 증권사 앱에 증거금 입금
D-0:  청약 첫날 개장 전 (오전 9시) 청약 신청 → 경쟁률 확인
D+1:  청약 마지막 날 오후 경쟁률 최종 확인
D+2:  환불 → 증거금 반환 확인
D+5~7: 상장일 전략 실행
