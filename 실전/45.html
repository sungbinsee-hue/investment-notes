HTS·MTS 실전 활용

도구를 모르면 전쟁터에서 총 사용법을 모르는 것과 같다.
HTS/MTS를 제대로 쓰면 정보 속도에서 개인투자자도 경쟁력을 가진다.

1. 주요 증권사 HTS·MTS 비교 (2026년)

HTS (Home Trading System, PC 프로그램) 비교

증권사 HTS명 장점 단점 추천 대상
키움증권 영웅문4 조건검색 최강, 차트 기능 우수, 수수료 저렴 UI 구식, 초보 진입장벽 적극적 트레이더
미래에셋 M-STOCK UI 깔끔, 해외주식 연동 우수 조건검색 약함 해외투자자
NH투자증권 NAMUH 균형잡힌 기능, 해외주식 수수료 상대적 높음 국내+해외 병행
삼성증권 POP 대형 IPO 참여, 안정적 기능 다양성 낮음 안정성 우선
한투증권 eFriend PLUS 기능 다양 UI 복잡 중급 이상

MTS (Mobile Trading System, 앱) 비교

증권사 앱명 장점 특징
토스증권 토스 UI 최강, 초보 친화, 소수점 매수 기능 단순, 수수료 무료
키움증권 영웅문S PC와 동일 조건검색, 기능 풍부 복잡한 UI
카카오페이증권 카카오페이 간편함, 연동 편의 기능 제한적

한국투자증권 뱅키스 IPO 청약 편의, 기능 다양

2. 호가창 완전 정복

호가창 구조

┌─────────────────────────────┐
│  매도 잔량  │  가격  │
├─────────────────────────────┤
│    2,500   │ 50,500 │ ← 매도5호가
│    1,800   │ 50,400 │ ← 매도4호가
│    3,200   │ 50,300 │ ← 매도3호가
│    5,100   │ 50,200 │ ← 매도2호가
│   10,500   │ 50,100 │ ← 매도1호가 (최우선 매도)
├─────────────────────────────┤
│ 현재가: 50,000              │
├─────────────────────────────┤
│    8,200   │ 49,900 │ ← 매수1호가 (최우선 매수)
│    6,500   │ 49,800 │ ← 매수2호가
│    4,100   │ 49,700 │ ← 매수3호가
│    2,800   │ 49,600 │ ← 매수4호가
│    1,500   │ 49,500 │ ← 매수5호가
└─────────────────────────────┘

호가창 해석법

매도 잔량 vs 매수 잔량 비교

매도 잔량 합계: 23,100
매수 잔량 합계: 23,100

매도 잔량 >> 매수 잔량 → 하락 압력 강함
매수 잔량 >> 매도 잔량 → 상승 압력 강함

허매수·허매도 주의

  • 대량 매수 호가가 쌓여 있다가 갑자기 사라지는 것
  • 실제 매수 의도 없이 매수세인 척 속이는 작전
  • 갑자기 사라지면 반대 방향으로 이동 예상

체결강도 해석

체결강도 = 매수 체결량 / 매도 체결량 × 100

체결강도 100%: 매수·매도 균형
체결강도 130%+: 매수 우위 → 상승 압력
체결강도 70%-: 매도 우위 → 하락 압력

3. 차트 설정 실전

추천 기본 차트 설정 (키움 영웅문 기준)

캔들: 일봉 기본
이동평균선: 5일(노랑), 20일(빨강), 60일(파랑), 120일(초록)
거래량: 하단 바차트
보조지표: RSI(14) + MACD(12,26,9)

타임프레임별 용도

타임프레임 용도 확인 항목
월봉 초장기 추세 10년 추세, 지지·저항
주봉 중기 추세 3~6개월 흐름
일봉 단기 추세 매매 타이밍 기본
60분봉 단기 진입 일중 고점·저점
15분봉 스캘핑 초단타 진입
💡 상위 타임프레임 먼저
주봉에서 하락 추세 → 일봉에서 단기 반등해도 공략 자제 주봉 상승 추세 + 일봉 눌림목 = 최적 매수 타이밍

4. 조건검색 실전 (키움 영웅문)

기본 조건검색 예시: 눌림목 매수 조건

조건 설정:
1. 주가 20일 이동평균선 위 (상승 추세 확인)
2. 주가 5일 이동평균선 아래 (단기 눌림목)
3. 거래량 평균의 50% 이하 (거래 감소 = 매도세 약화)
4. RSI 40~50 구간 (과매도에서 회복 초기)
5. 시가총액 500억 이상 (유동성 확보)

거래량 급증 조건

1. 전일 대비 거래량 300% 이상
2. 주가 전일 대비 +2% 이상 (거래량 + 상승)
3. 상한가·정지종목 제외
→ 세력 진입 또는 호재 발생 종목 발굴

52주 신고가 돌파 조건

1. 주가 52주 신고가 갱신
2. 거래량 전일 대비 200%+
3. 시가총액 1,000억 이상
→ 강한 모멘텀 종목 발굴

5. 주문 유형 완전 정리

주문 유형 체결 방식 장점 단점
시장가 즉시 최우선 체결 확실한 체결 불리한 가격 가능
지정가 지정 가격 이하 체결 원하는 가격 미체결 가능
최유리지정가 상대방 최우선 호가로 체결 신속 체결 시장가보다 불리할 수 있음
최우선지정가 내 쪽 최우선 호가로 체결 적정 가격 체결 미체결 가능
IOC 즉시 체결 안 되면 취소 확실한 타이밍 부분 체결 가능
FOK 전량 즉시 체결 또는 전량 취소 완전 체결만 체결 가능성 낮음

6. 실전 세팅 추천 (증권사별)

키움 영웅문 초기 세팅

1. 화면 분할: 차트 + 호가창 + 잔고/미체결 3분할
2. 관심종목 그룹: 보유종목 / 관심종목 / 매매대기 3그룹
3. 알림 설정: 목표가·손절가 도달 알림 설정
4. 단축키 설정: F1=매수, F2=매도, F3=취소
5. 조건검색 저장: 자주 쓰는 조건 저장

토스증권 초보 추천 기능

1. 소수점 매수: 테슬라 1주 못 사도 0.1주 매수 가능
2. 자동 환전: 달러 필요 시 자동 환전 (수수료 체크)
3. 자동 분할매수: 금액 설정 후 N회 분산 매수
4. 이유 알림: 주가 변동 원인 뉴스 자동 알림
