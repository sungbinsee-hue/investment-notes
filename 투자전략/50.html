퀀트 투자 기초

퀀트 = 감정 없이 숫자와 규칙으로만 투자하는 방법.
개인투자자도 엑셀·파이썬 없이 퀀터스·리밸런싱 앱으로 퀀트 투자 가능.

1. 퀀트 투자란?

정의와 특징

퀀트(Quant) 투자 = 수학적·통계적 모델을 이용해 투자 결정을 자동화

핵심 원칙:
- 감정 배제: "이 주식 오를 것 같다" 금지 → 숫자만
- 규칙 기반: 매수·매도 조건 사전 정의
- 백테스트: 과거 데이터로 전략 검증
- 분산투자: 수십~수백 종목 동시 보유
- 리밸런싱: 주기적(월·분기·연 1회) 포트폴리오 재구성

퀀트 투자 vs 일반 투자

항목 퀀트 투자 일반 주관적 투자
의사결정 규칙 (자동) 직관·판단
감정 영향 없음 큼 (공포·탐욕)
보유 종목 수 20~100개+ 5~20개
시간 투입 리밸런싱만 지속적 모니터링
초과수익 근거 팩터 프리미엄 정보 우위

2. 주요 팩터 (Factor)

팩터란?

팩터 = 초과수익을 설명하는 체계적인 특성

학술 연구로 검증된 팩터:
1. 가치(Value): 저PBR·저PER → 저평가 주식 우위
2. 모멘텀(Momentum): 최근 상승 주식 계속 상승
3. 소형주(Size): 소형주 > 대형주 장기 수익률
4. 퀄리티(Quality): 고ROE·저부채 기업 우위
5. 저변동성(Low Volatility): 변동성 낮은 주식 위험 대비 수익 우위

팩터별 특성

팩터 대표 지표 작동 원리 약점
가치 PBR, PER, EV/EBITDA 저평가 정상화 가치 함정 위험
모멘텀 12개월 수익률 (최근 1개월 제외) 추세 지속성 급등 후 급락
소형주 시가총액 하위 저평가·성장 여력 유동성 위험
퀄리티 ROE, 이익 안정성 지속 성장 기업 고평가 위험
저변동성 52주 표준편차 비이성적 선호 상승장 부진

3. 주요 퀀트 전략

마법공식 (Joel Greenblatt)

마법공식 = 이익수익률 + 투하자본이익률(ROIC) 두 지표 조합

1. 이익수익률 = EBIT / 기업가치(EV) → 높을수록 좋음
2. ROIC = EBIT / 투하자본 → 높을수록 좋음

방법:
- 전체 종목에서 이익수익률 순위 계산
- ROIC 순위 계산
- 두 순위의 합산이 낮은 종목 20~30개 선택
- 연 1회 리밸런싱

백테스트 결과 (미국 1988~2004):
→ 연평균 30.8% vs S&P500 연 12.4%

모멘텀 전략

12-1 모멘텀 = 12개월 전 대비 현재 수익률 (단, 최근 1개월 제외)

이유: 최근 1개월 수익률은 단기 반전 효과로 노이즈

실전 방법:
1. 전체 종목에서 12-1 모멘텀 계산
2. 상위 20% 종목 균등 보유
3. 월 1회 리밸런싱

주의: 모멘텀 크래시 (2009년 3월 같은 급반등 장세에서 큰 손실)

저PBR 전략 (국내 적합)

한국 주식시장 특성: 선진국 대비 저PBR 코리아 디스카운트

저PBR 전략:
1. 코스피·코스닥 전체에서 PBR 하위 20% 선정
2. 부채비율 200% 초과 제거
3. 적자 기업 제거
4. 20~30종목 균등 보유
5. 분기 1회 리밸런싱

2024년 코리아 디스카운트 해소 정책 시작 → 저PBR 종목 수혜 기대

F-Score (Piotroski)

F-Score = 재무 건전성 9가지 항목 점수 합산

항목 (각 1점):
수익성:
1. ROA > 0 (당기 수익)
2. 영업현금흐름 > 0
3. ROA 전년비 증가
4. 영업현금흐름 > 순이익 (발생주의 조정)

레버리지·유동성:
5. 부채비율 전년비 감소
6. 유동비율 전년비 증가
7. 신주발행 없음

효율성:
8. 매출총이익률 전년비 증가
9. 자산회전율 전년비 증가

F-Score 0~2: 약한 기업 (매도 신호)
F-Score 7~9: 강한 기업 (매수 신호)

4. 멀티팩터 전략 (추천)

단일 팩터의 한계

단일 팩터 문제:
- 가치 팩터: 2010~2020년 10년간 부진
- 모멘텀 팩터: 2009·2020 급반등 장세에서 큰 손실
- 소형주 팩터: 유동성 위험

해결: 팩터 조합으로 분산
→ 각 팩터의 약점을 다른 팩터가 보완

추천 멀티팩터 조합

전략명 팩터 조합 리밸런싱 국내 적용
가치+모멘텀 저PBR + 12-1 모멘텀 월 1회 적합
퀄리티+가치 고ROE + 저PER 분기 1회 적합
올웨더 팩터 가치+모멘텀+퀄리티 월 1회 적합

5. 국내 퀀트 투자 도구

퀀터스 (Quantus, 추천)

퀀터스 (quantus.kr):
- 코스피·코스닥 전체 백테스트 가능
- 팩터 선택 → 종목 필터 → 성과 확인
- 백테스트 기간: 2000년~현재
- 매월 리밸런싱 종목 자동 생성
- 유료 구독 (월 2~3만원)

아이투자 (I-Value)

아이투자 (itooza.com):
- 국내 주식 재무 데이터 무료 제공
- 가치주 스크리닝 특화
- F-Score, 마법공식 자동 계산

6. 퀀트 투자 실전 설계

초보자 퀀트 전략 예시

전략: 국내 저PBR + 고ROE 멀티팩터
대상: 코스피·코스닥 전체
필터: 
  - 시가총액 500억 이상
  - 부채비율 150% 이하
  - 최근 2년 연속 흑자
  - PBR 하위 30%
  - ROE 상위 30%
  - 두 조건 합산 상위 30종목 선정

보유 비중: 균등 (각 3.3%)
리밸런싱: 분기 1회

리밸런싱 비용 고려

리밸런싱 비용:
- 수수료: 매수·매도 각 0.015% × 2 = 0.03%
- 세금: 양도세 없음 (국내 주식)
- 슬리피지: 소형주 일수록 높음 (~0.1~0.3%)

월 1회 리밸런싱: 연간 비용 ~0.5~1%
분기 1회 리밸런싱: 연간 비용 ~0.2~0.5%

→ 소형주 전략은 분기 리밸런싱 추천
→ 대형주 전략은 월 리밸런싱 가능

백테스트 주의사항

생존자 편향(Survivorship Bias):
→ 현재 존재하는 기업만 포함하면 결과 과장
→ 퀀터스는 상장폐지 종목 포함하여 해결

전진 분석(Out-of-Sample Test):
→ 2000~2015년 백테스트 → 2016~현재 검증
→ 과적합(Overfitting) 방지

과최적화 경고:
→ 변수가 많을수록 과거에만 맞는 전략 위험
→ 단순한 전략이 장기적으로 더 강건
