기술적 분석 기초

기술적 분석은 과거 가격·거래량 데이터로 미래 방향성을 예측하는 기법.
매수·매도 타이밍 보조 도구로 활용. 단독 의존은 위험.

1. 캔들 차트

캔들 하나의 구조

  │  ← 위꼬리 (고가)
 ┌┴┐
 │ │ ← 몸통 (시가~종가)
 └┬┘
  │  ← 아래꼬리 (저가)
  • 양봉 (빨간색): 종가 > 시가 → 상승 마감
  • 음봉 (파란색/검정): 종가 < 시가 → 하락 마감

주요 캔들 패턴

패턴 모양 신호
장대양봉 몸통 크고 꼬리 짧음 강한 매수세
장대음봉 몸통 크고 꼬리 짧음 강한 매도세
도지 몸통 거의 없음 매수·매도 균형, 추세 전환 가능성
망치형 아래꼬리 길고 몸통 작음 하락 후 반등 신호
역망치형 위꼬리 길고 몸통 작음 상승 후 하락 전환 가능성
십자형 도지 완전 균형 강한 전환 신호

2. 이동평균선 (MA, Moving Average)

일정 기간의 평균 주가를 선으로 연결. 추세 확인 도구.

주요 이동평균선

기간 용도
5일선 초단기 추세, 데이 트레이더 사용
20일선 단기 추세, 개인투자자 가장 많이 참고
60일선 중기 추세
120일선 장기 추세, 기관·외국인 참고
200일선 미국 시장에서 장기 추세 기준선

골든크로스 & 데드크로스

골든크로스: 단기 이동평균선이 장기 이동평균선을 아래에서 위로 돌파 → 상승 신호

20일선이 60일선 위로 상향 돌파 → 골든크로스 → 매수 신호

데드크로스: 단기 이동평균선이 장기 이동평균선을 위에서 아래로 하향 돌파 → 하락 신호

20일선이 60일선 아래로 하향 돌파 → 데드크로스 → 매도 신호
⚠️ 후행성 지표
이동평균선은 과거 데이터 기반 → 신호 발생 시점이 늦을 수 있음. 강한 추세 확인용으로 활용하되 단독 의존 금지.

3. RSI (Relative Strength Index, 상대강도지수)

0~100 범위로 과매수·과매도 상태 측정. 14일 기준 가장 많이 사용.

해석

RSI 구간 의미 행동 고려
70 이상 과매수 과열 → 조정 가능성, 매도 검토
50~70 상승 추세 보유·추가 매수
30~50 하락 추세 관망·분할 매수 검토
30 이하 과매도 급락 → 반등 가능성, 매수 검토

RSI 다이버전스 (중요)

강세 다이버전스: 주가는 신저점 갱신, RSI는 더 높은 저점 형성 → 상승 전환 신호

약세 다이버전스: 주가는 신고점 갱신, RSI는 더 낮은 고점 형성 → 하락 전환 신호

4. MACD (Moving Average Convergence Divergence)

단기 이동평균과 장기 이동평균의 차이로 추세 강도·전환 포착.

구성 요소

  • MACD 선: 12일 EMA - 26일 EMA
  • 시그널 선: MACD의 9일 EMA
  • 히스토그램: MACD - 시그널 선

매매 신호

매수 신호: MACD 선이 시그널 선을 아래에서 위로 돌파 (골든크로스)

매도 신호: MACD 선이 시그널 선을 위에서 아래로 하향 돌파 (데드크로스)

히스토그램 해석:
- 양수 + 증가 → 상승 모멘텀 강화
- 양수 + 감소 → 상승 모멘텀 약화 (조정 예고)
- 음수 + 감소 → 하락 모멘텀 강화

5. 지지선 & 저항선

지지선 (Support)

주가가 하락하다 멈추는 가격대. 매수세가 집중되는 수준.

주가가 50,000원 부근에서 3번 반등 → 50,000원이 강한 지지선

저항선 (Resistance)

주가가 상승하다 막히는 가격대. 매도세가 집중되는 수준.

주가가 70,000원에서 3번 하락 → 70,000원이 강한 저항선

지지-저항 역할 전환

지지선이 붕괴되면 → 그 수준이 새로운 저항선이 됨
저항선이 돌파되면 → 그 수준이 새로운 지지선이 됨

6. 거래량 분석

거래량은 주가 움직임의 신뢰도를 검증하는 도구.

기본 원칙

상황 신뢰도
주가 상승 + 거래량 증가 강한 상승 신뢰
주가 상승 + 거래량 감소 약한 상승 (지속성 의심)
주가 하락 + 거래량 증가 강한 하락 신뢰
주가 하락 + 거래량 감소 조정 마무리 가능성

거래량 급증 패턴

  • 돌파 시 거래량 급증: 저항선 돌파 확인 → 신뢰도 높음
  • 바닥권 거래량 급증: 패닉 셀링 마무리 신호 가능성

7. 기술적 분석 활용 원칙

💡 실전 원칙
1. **여러 지표 중첩 확인**: RSI 과매도 + 지지선 + 거래량 급증 → 신뢰도 증가 2. **상위 타임프레임 우선**: 주봉·월봉 추세 확인 후 일봉 매매 타이밍 결정 3. **펀더멘털 먼저**: 기술적 신호는 매수·매도 타이밍 보조. 기업 가치 분석이 선행 4. **과거 패턴 = 확률**: 100% 맞는 지표는 없음. 확률적 도구로 활용
⚠️ 기술적 분석의 한계
- 예측이 아닌 후행 확인 도구 - 뉴스·공시·외국인 수급 변수에 패턴 붕괴 가능 - 단기 매매보다 중장기 추세 확인에 더 유용
