절세 포트폴리오 분배 전략

이 노트는 "어디에 얼마씩 넣는 것이 합리적인가"에 대한 전문가적 설계안이다.
아래 예시는 총급여 5,500만원 초과 구간 기준으로 작성되었다.

1. 월 현금흐름 기반 설계

월 수입·지출 구조 (예시)

항목 금액 (월)
세후 월 실수령 개인별 상이
생활비 (식비·교통·통신 등) ≈ 100~130만 원
주거비 (월세·관리비) ≈ 50~80만 원
비상금 적립 (초기 목표 달성 전) ≈ 30만 원
투자·절세 가용 자금 ≈ 150만 원 내외 (예시)

개인 지출 구조에 따라 다름. 아래 전략은 월 여유자금 150만 원 가용 예시 기준.

2. 우선순위 기반 자금 배분

원칙: 유동성 → 세액공제 → 비과세 → 소득공제 순

[단계 1] 비상금 확보 (선행 필수)
          목표: 월 생활비 × 6개월 = 약 1,200~1,500만 원
          수단: CMA, 파킹통장 (이율 3~4%)

[단계 2] IRP + 연금저축 900만원 채우기 (확정 이익 118.8만원)
          월 75만원 자동이체 → 연 900만원 달성

[단계 3] ISA 중개형 납입 (비과세 + 투자 자유도)
          월 30~50만원 → 연 360~600만원

[단계 4] 주택청약저축 300만원 (연 19.8만원 절세)
          월 25만원 → 연 300만원

[단계 5] 국민성장펀드 (유동성 희생 조건부)
          여유자금 500~3,000만원 일시 납입

[단계 6] 카드 전략 최적화 (추가 최대 49.5만원)
          체크카드 비중 확대, 전통시장 활용

3. 월 여유자금 기준 최적 분배안 (150만원 예시)

항목 월 납입액 연 납입액 연 절세효과 우선도
IRP (300만/년) 25만 원 300만 원 포함 ★★★★★
연금저축 (600만/년) 50만 원 600만 원 포함 ★★★★★
IRP+연금저축 합계 75만 원 900만 원 118.8만 원
ISA 중개형 40만 원 480만 원 수익 발생 시 ★★★★☆
주택청약저축 25만 원 300만 원 19.8만 원 ★★★☆☆
잔여 자유 투자 10만 원 120만 원 — ★★☆☆☆
합계 150만 원 1,800만 원 ≈ 138.6만 원

4. 국민성장펀드 편입 시나리오

국민성장펀드는 5년 만기 폐쇄형이라 월 납입이 아닌 여유자금 일시 투자 방식.

편입 여부 판단 트리

비상금 1,200만원 보유? ──No──→ 국민성장펀드 보류
                │
               Yes
                │
        5년 내 대형 지출 계획? ──Yes──→ 국민성장펀드 보류
                │
               No
                │
        여유자금 규모는? ──500만 미만──→ 절세 효과 미미, 보류
                │
         500~3,000만원
                │
              편입 적합 (소득공제 40% 구간 내)

여유자금별 추천 투자금

여유자금 추천 투자금 이유
500만 원 500만 원 40% 공제 구간, 절세 33만원
1,000만 원 1,000만 원 절세 66만원, 적정 리스크
3,000만 원 이상 최대 3,000만 원 40% 구간 최대 활용 (절세 198만)
5,000만 원 이상 3,000만 원 권고 3,001만~5,000만 구간은 효율 절반 하락

5. 절세 항목별 시계(Time Horizon) 구분

단기 (연내 회수)
  └── 카드 전략 → 연말정산 직후 환급
  └── 의료비 세액공제 → 연말정산 직후 환급

중기 (3년 내)
  └── ISA 중개형 → 3년 만기 후 연금 이전 or 현금 회수

장기 (5년)
  └── 국민성장펀드 → 5년 만기 후 수령

초장기 (55세 이후)
  └── IRP + 연금저축 → 55세 이후 연금 수령 (세율 3.3~5.5%)

6. 연도별 절세 효과 누적 시뮬레이션

가정: 풀 시나리오 실행 (IRP+연금+ISA+청약+카드)

연도 당해 절세액 누적 절세액
1년 차 138.6만 원 + 카드 49.5만 ≈ 188만 원
2년 차 동일 ≈ 376만 원
3년 차 동일 + ISA 만기 연금 이전 추가 ≈ 600만 원
5년 차 국민성장펀드 만기 + 누적 ≈ 1,100~1,400만 원

ISA → 연금 이전 세액공제 (최대 39.6만 원)는 이전 연도에 발생.
국민성장펀드 소득공제는 납입 1년 차에만 발생 (이후 수익에 9.9% 분리과세).

7. 세제 혜택 수령 방식 비교

혜택 방식 수령 시기 체감 방식
세액공제 (IRP·연금저축) 다음 해 1~2월 연말정산 급여명세서 환급 or 세금 감소
소득공제 (청약·카드) 동일 과세표준 감소 → 세금 감소
국민성장펀드 소득공제 납입 해당 연도 연말정산 소득공제 → 세금 감소
ISA 비과세 만기 정산 시 수익에서 세금 미차감
연금 수령 시 절세 55세 이후 낮은 세율 연금소득세

8. 리스크별 자산 배분 원칙

유동성 자산 (언제든 쓸 수 있어야 하는 것)
  → CMA / 파킹통장: 비상금 1,200만원 + 단기 목적 자금

중기 투자 (3년 내 필요 가능)
  → ISA 중개형: 연 480만 원 적립

장기 투자 (5년 이상 확실히 안 써도 됨)
  → IRP + 연금저축: 연 900만 원 (노후 자금)
  → 국민성장펀드: 여유자금 (5년 묶임 감수)

절대 건드리지 말 것
  → IRP·연금저축 (55세 이전 인출 시 기타소득세 16.5%)
  → 국민성장펀드 (3년 내 해지 시 세금 전액 추징)

9. 전문가 총평

총급여 5,500만원 초과 구간은 절세 전략의 '전환점'이다.
5,500만원 경계를 넘으면 세액공제율이 16.5%→13.2%로 낮아지고,
5,000만원을 넘으면 ISA 서민형(비과세 400만)도 사용 불가다.
이 구간에서는 소득공제형 상품(국민성장펀드, 주택청약, 카드)의 상대적 가치가 높아진다.
세액공제율 하락을 '소득공제'로 보완하는 것이 핵심 전략이다.

우선순위 요약 (최종):
1. 비상금 1,200만 원 → 먼저
2. IRP + 연금저축 900만 원 → 매년 기본
3. ISA 중개형 개설 + 적립 → 지금 개설 (의무기간 카운트)
4. 주택청약 300만 원 → 청약 계획 있으면 필수
5. 국민성장펀드 → 여유자금 500만 원 이상, 5년 유동성 감수 가능 시
6. 카드 전략 → 체크카드 비중 확대 (추가 비용 없이 소득공제 최적화)
